# Feel Log

Feel Log é um diário pessoal para registrar pensamentos, sentimentos e momentos do dia a dia.

O projeto foi desenvolvido com HTML, CSS e JavaScript, usando Firebase para autenticação e armazenamento das entradas.

## Funcionalidades

- Login com Firebase Authentication
- Criação de registros
- Edição e exclusão de entradas
- Seleção de múltiplos sentimentos
- Histórico de registros
- Rascunho automático
- Sincronização entre dispositivos

## Tecnologias

- HTML
- CSS
- JavaScript
- Firebase Authentication
- Cloud Firestore
- GitHub Pages

## Objetivo

Criar um espaço simples e pessoal para manter o hábito de escrever e registrar como me sinto.
